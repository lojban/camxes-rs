# tables/

Embedded gismu / rafsi data for constraint **C23** (and C13 hyphen necessity).

- `rafsi_data.rs` — generated from LLG 1994-09-26 baselined wordlists (CLL §4.11 companion).
- `rafsi_provenance.json` — machine-readable provenance note.
- **Not** jbovlaste experimental rafsi.

See the “Phonology and word classes” section of the repository README for the lexicon’s role and provenance.
